# Image sources & licensing

BloomNest ships with **zero third-party images**. Every visual in the app is
project-original artwork, generated as SVG, so there is no copyright risk and
the app works fully offline.

## What exists and where it comes from

| Asset | Count | Source |
|---|---|---|
| Product illustrations (`frontend/public/images/products/*.svg`) | 28 | Generated by `scripts/generate-images.mjs` |
| Product image catalog (`frontend/public/images/products/manifest.json`) | 1 | Written by the same generator |
| Hero illustration, logo, favicon (`frontend/public/images/*.svg`) | 3 | Hand-written original SVG in-repo |
| Admin-uploaded product photos (`/uploads/…`) | runtime | Uploaded via the admin panel; validated by magic bytes, stored in the `bloomnestuploads` Docker volume |

## How the generator works

`scripts/generate-images.mjs` is a deterministic illustration generator:

- A **seeded PRNG** (FNV-1a hash of the product slug → xorshift) picks petal
  shapes, rotations and shades, so the *same slug always produces the same
  picture* — re-running the script never churns the repo.
- All drawings use the project palette (cream `#faf6ee`, forest greens
  `#3f6b4f` / `#2f5d3a` / `#7fa88c`) to match the storefront theme.
- Output is plain SVG text committed to the repo — no network fetch, no fonts,
  no embedded rasters.

Regenerate at any time (host Node or any container):

```bash
node scripts/generate-images.mjs
```

- No stock-photo sites, AI image services or external CDNs were used.
